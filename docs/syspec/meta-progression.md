# Meta Progression

Progress that carries over between runs. All of the following are in scope:

| Unlock type | Description |
|---|---|
| Cars | New cars with their own handling and starting parts |
| Items and threats | New items (and threats) added to the random pool (RoR2 style) |
| Drivers / co-drivers | Characters with perks (e.g. better pace notes, cheaper repairs) |
| Cosmetic liveries | 90s-style paint schemes and decals |
| Permanent stat upgrades | Small permanent bonuses (Rogue Legacy style) |
| Mount points | 2 extra mount points beyond the base 4 (e.g. trailer hitch) |
| Endings | Area 51 alternative ending |
